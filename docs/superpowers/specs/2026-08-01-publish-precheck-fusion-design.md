# 发布前审融合设计

## 目标

将 `yuwen-cool/yuwen-publish-precheck` 的可迁移方法融合到 `wb-xhs-humanize-compliance`，让小红书技能在改稿后同时检查标题、封面文字、图片文字、正文、案例证据、商业披露和行动引导，并在修复后复检。

## 约束

- 保留 WorkBuddy 原有去 AI 味、内容诊断、图文拆页和视觉可读性能力。
- 采用“候选扫描 → 语义复核”的两层判断；不把关键词命中或零命中当最终结论。
- 只做保意修复，不提供绕过审核的做法，不复制来源规则库。
- 来源仓库 CC BY-NC 4.0，README 与技能审计信息保留署名。

## 验收标准

技能能输出 `可发 / 需修改 / 暂不建议发`，按“必须改 / 建议改 / 待确认”列出具体风险与替换文本，改写后有复检结果；测试提示覆盖正常预审和拒绝规避审核两类场景。
