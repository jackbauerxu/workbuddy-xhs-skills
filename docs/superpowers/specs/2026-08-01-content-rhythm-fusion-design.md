# 小红书内容节奏与内容管线融合设计

日期：2026-08-01

## 目标

把 yanliudreamer 的《0基础小红书教程(下)｜从0到1万粉：内容节奏怎么排？》转译为当前 WorkBuddy 小红书 Skills 可执行的内容管线与阶段决策，而不是照抄原文或把固定发帖频率当成保证。

## 范围

- `wb-xhs-schedule-review`：新增内容输入—加工—库存—输出管线、两周缓冲、四阶段节奏模型、拉新/信任/标签循环和阶段化复盘字段。
- `wb-xhs-account-profile`：补充“内容垂直 → 人设垂直”的过渡规则，以及方向、标签、信任三类长期资产。
- `wb-xhs-topic-bank`：补充拉新/信任/标签意图字段和“问题—经验—观点”无灵感兜底模板。
- README、INDEX、FUSION_NOTES、DIGEST、verified 与来源说明：让项目介绍、方法谱系和验收记录与新能力一致。
- 对应测试提示：覆盖阶段判断、库存不足、爆款系列化、人设垂直和兜底模板。

## 非目标

- 不承诺固定发帖频率、涨粉数量或平台分发结果。
- 不把原帖的 40/30/30、50/30/20、60/20/20 当成所有赛道的硬规则；它们是可调整的起始假设。
- 不新增股票、投资或其他与小红书内容生产无关的脚本范围。
- 不复制原文长段落、图片或作者专属经历。

## 验收标准

1. 排期技能能根据账号阶段输出内容目标、建议比例、库存目标、发布/生产节奏和下一轮实验，而不是只给日历。
2. 排期技能明确“内容节奏不是固定频率”，并在库存低于安全缓冲时优先补库存或降低承诺，不鼓励临时赶稿。
3. 账号档案能区分早期内容垂直、中期人设垂直和多元内容应放主号、小号或矩阵的条件。
4. 选题库能为每个题目标注拉新、建立信任或强化标签的主要目的；无灵感时能套用问题—经验—观点并保留真人素材。
5. README 与来源记录能说明本次融合的仓库、帖子、能力边界和不保证项。
6. 新增测试提示能检查以上行为，JSON、Skill frontmatter、源/安装副本和仓库结构验证通过。
